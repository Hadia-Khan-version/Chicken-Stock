# Chicken Stock 

## Project Overview

Chicken Stock is a stock portfolio management system focused on the Pakistan Stock Exchange (PSX). It aims to help users track stock prices, manage their holdings, calculate profit and loss, and visualize portfolio performance using available market data.

## Objectives

- Retrieve Pakistani stock market data.
- Manage personal stock holdings and transactions.
- Calculate investment value and profit/loss.
- Visualize stock prices and portfolio performance.
